## TAREA 19 — Tratamiento especial del producto LECHE en el Reporte General

### Descripción del problema

El producto **LECHE** existe en `condoriri.productos` vinculado a registros de inventarios de materia prima LECHE. A diferencia del resto de productos terminados (YOGURT, QUESO, etc.), LECHE:

- **No tiene MERMA** (`merma` siempre `NULL` en BD)
- **No tiene AGREGA** (`agrega` siempre `NULL` en BD)
- Representa litros de leche producida / procesada internamente

Actualmente el reporte la trata igual que al resto de productos, generando 4 columnas (`Stock`, `Cant.Prod`, `MERMA`, `AGREGA`) de las cuales 2 siempre muestran `-` o `0`. Esto desperdicia espacio y genera confusión.

### Cambio requerido

LECHE debe mostrarse como una **columna única** con encabezado `LECHE (L)` que muestra únicamente `cantidad_produccion`. No lleva columnas de stock, merma ni agrega.

---

### Análisis técnico

#### Estado en BD confirmado (consulta directa)

```
condoriri.productos WHERE nombre = 'LECHE'
→ merma:  NULL (siempre)
→ agrega: NULL (siempre)
→ cantidad_produccion: valor numérico (litros producidos)
→ stock: igual a cantidad_produccion
```

#### Impacto en la lógica de columnas

Actualmente cada producto ocupa **4 columnas**: `Stock | Cant.Prod | MERMA | AGREGA`

Con el cambio, LECHE ocupará **1 columna**: `LECHE (L)`

Esto implica:
- LECHE debe **extraerse de `$productosUnicos`** y manejarse por separado
- El cálculo de anchos dinámicos debe restar el espacio de LECHE (1 columna, no 4)
- En encabezados, datos y totales: LECHE tiene su propia celda simple tras RESERVA

### Cambios detallados

---

#### CAMBIO A — `app/Libraries/ReporteLacteos.php` (PDF)

##### A1. Nuevo método auxiliar `esProductoSimple(string $nombre): bool`

```php
private function esProductoSimple(string $nombre): bool
{
    return strtoupper(trim($nombre)) === 'LECHE';
}
```

##### A2. Modificar `calcularAnchos()`

- Separar productos en dos grupos: **simples** (LECHE) y **complejos** (resto)
- El ancho disponible para productos complejos se reduce en el ancho de columnas simples
- Columnas simples: ancho fijo igual a `$wProd` (una sola columna)
- Parámetro actual: `int $numProductos` → cambiar a recibir `array $productosUnicos`

**Lógica de ancho:**
```
wFijas     = wFecha + wTurno + wStock + wReserva
wSimples   = count(simples) * wProd          (1 col por producto simple)
wMATotal   = count(complejos) * 2 * wMA      (MERMA+AGREGA por producto complejo)
wDinamica  = pageW - wFijas - wSimples - wMATotal
wProd      = max(12, floor(wDinamica / (count(complejos) * 2)))
```

##### A3. Modificar `anchoTotal()`

```php
private function anchoTotal(array $productosUnicos): float
{
    $simples  = array_filter($productosUnicos, fn($n) => $this->esProductoSimple($n));
    $complejos = array_filter($productosUnicos, fn($n) => !$this->esProductoSimple($n));
    return $this->wFecha + $this->wTurno + $this->wStock + $this->wReserva
         + count($simples) * $this->wProd
         + count($complejos) * (2 * $this->wProd + 2 * $this->wMA);
}
```

##### A4. Modificar `filasEncabezados()`

- Después de las columnas fijas (FECHA, TURNO, CANT. LECHE, RESERVA), iterar `$productosUnicos`:
  - Si `esProductoSimple($nombre)`: generar **1 celda** con etiqueta `LECHE (L)`, estilo igual a las otras columnas de producto (color `#5D8A8A`)
  - Si no: generar las 4 celdas habituales (`Stk`, `Prod`, `MERMA`, `AGREGA`)

##### A5. Modificar `filasDatos()`

- En el bucle de productos:
  - Si `esProductoSimple($nombre)`: imprimir **1 celda** con `cantidad_produccion` (o `-` si null)
  - Si no: imprimir las 4 celdas habituales

##### A6. Modificar `filaTotalMes()`

- En el bucle de sumas de productos:
  - Si `esProductoSimple($nombre)`: imprimir **1 celda** con la suma de `cantidad_produccion`
  - Si no: imprimir las 4 celdas habituales de total

##### A7. Propagación: llamadas a `calcularAnchos()` y `anchoTotal()`

- `generarReporte()` llama `$this->calcularAnchos(count($productosUnicos))` → cambiar a `$this->calcularAnchos($productosUnicos)`
- Todas las llamadas a `anchoTotal(count($productosUnicos))` → cambiar a `anchoTotal($productosUnicos)`
