## TAREA 9 — Normalización de nombres en formularios de registro de clientes

### Solicitud del cliente

Los nombres registrados para clientes deben cumplir las normas institucionales:
1. **Formato obligatorio:** `APELLIDO_PATERNO APELLIDO_MATERNO NOMBRE(S)` — mínimo 3 palabras
2. **Mayúsculas:** todo en mayúsculas
3. **Controles en formulario:** guiar al operador con placeholder, texto de ayuda y validación
   antes de enviar — no solo depender del backend

Aplica únicamente a:
- **Clientes contado** (`condoriri.clientes.nombre_completo`)
- **Clientes externos** (`condoriri.clientes_externos.nombre`)

Los usuarios del sistema (`condoriri.usuarios`) quedan **excluidos** de esta tarea.

### Cambios definidos

#### Cambio A — Vistas: 3 inputs separados + validación JS

Reemplazar el input único `nombre_completo` / `extNombre` por 3 inputs separados:

| Input | Name | Obligatorio | Ejemplo |
|---|---|---|---|
| Apellido Paterno | `apellido_paterno` | ✅ Sí | `MAMANI` |
| Apellido Materno | `apellido_materno` | ❌ Opcional | `QUISPE` |
| Nombre(s) | `nombres` | ✅ Sí | `JUAN CARLOS` |

- Cada input con `style="text-transform:uppercase"` para feedback visual inmediato
- Placeholder descriptivo en cada campo
- Validación JS antes del submit: `apellido_paterno` y `nombres` no pueden estar vacíos
- El formulario **no envía** `nombre_completo` directamente — el backend concatena

#### Cambio B — Backend: concatenar 3 inputs y validar

El backend recibe los 3 campos por separado, los concatena y guarda en el campo único de BD:

```php
$apellidoPaterno = strtoupper(trim($this->request->getPost('apellido_paterno') ?? ''));
$apellidoMaterno = strtoupper(trim($this->request->getPost('apellido_materno') ?? ''));
$nombres         = strtoupper(trim($this->request->getPost('nombres') ?? ''));

if (empty($apellidoPaterno) || empty($nombres)) {
    // error: apellido paterno y nombre(s) son obligatorios
}

$nombreCompleto = trim(implode(' ', array_filter([$apellidoPaterno, $apellidoMaterno, $nombres])));
// Resultado: "MAMANI QUISPE JUAN CARLOS" o "MAMANI JUAN" si no hay materno
```

Esto reemplaza la validación de “mínimo 3 palabras” del Cambio B anterior — la estructura
de 3 inputs garantiza el formato por diseño, sin necesidad de contar palabras.
