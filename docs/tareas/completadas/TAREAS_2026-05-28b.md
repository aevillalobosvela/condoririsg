## TAREA 13 — Bandeja de presets en formulario de creación de productos (`/productos/register`)

### Solicitud del cliente

En el formulario de creación de productos (`/productos/register/:inventarioId`), agregar
una **bandeja de presets** que permita al operador seleccionar un producto conocido y que
el sistema complete automáticamente nombre, unidad y precios. El llenado manual de todos
los campos debe seguir siendo posible — los presets son una ayuda, no un reemplazo.

### Decisión de diseño

**Presets hardcodeados en la vista** (no en BD, no en controller).

Razones:
- Los presets son una ayuda de UX, no datos de negocio — no necesitan persistencia.
- Los precios cambian con el tiempo; el operador los ajusta manualmente después de
  seleccionar el preset. El preset solo evita escribir el nombre y seleccionar la unidad.
- Agregar una tabla de BD o un endpoint AJAX para 7 presets sería sobreingeniería.
- Si en el futuro se necesita gestión dinámica de presets, se puede migrar a BD.

**Alternativa descartada:** endpoint AJAX que devuelva el último precio usado por nombre.
Descartada porque añade latencia, complejidad y un endpoint nuevo para un beneficio marginal
(los precios son estables semana a semana y el operador los revisa antes de guardar).

### Diseño de la bandeja

#### Apariencia

Bandeja de botones compactos encima del campo "Producto", visible solo en modo creación
(`!isset($producto->id)`). Cada botón muestra el nombre del producto en 2 líneas:
- Línea 1: nombre corto (ej. `QUESO`)
- Línea 2: presentación (ej. `900 g`)

Al hacer clic en un preset:
1. El campo `#nombre` se rellena con el nombre completo del preset
2. El `<select #unidad_id>` se establece al `unidad_id` del preset
3. Los campos `#precio_contado` y `#precio_credito` se rellenan con los precios del preset
4. El botón del preset seleccionado recibe clase `active` (borde verde destacado)
5. Si el operador modifica cualquier campo manualmente, el preset queda "deseleccionado"
   visualmente (se quita la clase `active`) — los datos ya rellenados no se borran

#### Comportamiento detallado

- La bandeja aparece solo en modo creación (no en edición).
- Seleccionar un preset **no bloquea** ningún campo — todo sigue editable.
- El campo `#nombre` se convierte a mayúsculas automáticamente (ya lo hace el backend,
  se agrega `style="text-transform:uppercase"` al input para feedback visual).
- Si el operador borra el nombre o cambia la unidad manualmente, el botón activo
  se deselecciona visualmente pero los demás campos no se revierten.
- El preset no toca los campos de cálculo (`cantidad_produccion`, `cantidad_unidad`,
  `stock`, `reserva`) — esos siguen su lógica existente.
- El preset no toca los campos de calidad ni la imagen.

  </small>

#### JS — lógica de presets

```js
const PRESETS = [ /* 7 objetos definidos arriba */ ];

// Renderizar botones
const container = document.getElementById('presetBtns');
PRESETS.forEach((p, i) => {
  const btn = document.createElement('button');
  btn.type = 'button';
  btn.className = 'btn btn-sm btn-outline-success preset-btn';
  btn.dataset.idx = i;
  btn.style.cssText = 'white-space:pre-line; font-size:0.72rem; line-height:1.2; min-width:72px;';
  btn.textContent = p.label;
  btn.addEventListener('click', () => applyPreset(i));
  container.appendChild(btn);
});

function applyPreset(idx) {
  const p = PRESETS[idx];
  document.getElementById('nombre').value         = p.nombre;
  document.getElementById('unidad_id').value      = p.unidad_id;
  document.getElementById('precio_contado').value = p.precio_contado;
  document.getElementById('precio_credito').value = p.precio_credito;

  // Marcar botón activo
  document.querySelectorAll('.preset-btn').forEach(b => b.classList.remove('active'));
  document.querySelector(`.preset-btn[data-idx="${idx}"]`).classList.add('active');
}

// Deseleccionar preset si el operador edita nombre o unidad manualmente
['nombre', 'unidad_id'].forEach(id => {
  document.getElementById(id)?.addEventListener('input', () => {
    document.querySelectorAll('.preset-btn').forEach(b => b.classList.remove('active'));
  });
  document.getElementById(id)?.addEventListener('change', () => {
    document.querySelectorAll('.preset-btn').forEach(b => b.classList.remove('active'));
  });
});
```
