## TAREA 17 — Acceso del rol `almacen` a la pantalla de gestión de clientes

### Solicitud del cliente

El rol `almacen` necesita acceder a la pantalla de gestión de clientes (`/cliente/lista`) desde el sidebar, con permisos para editar clientes al contado.

---

### Diagnóstico del estado actual

#### Rutas (`app/Config/Routes.php`)

El grupo `cliente` tiene el siguiente estado:

| Ruta | Roles actuales |
|---|---|
| `GET /cliente/lista` | admin, vendedor, agropecuario, ganaderia |
| `POST /cliente/create` | admin, vendedor, agropecuario, ganaderia, **almacen** ✅ |
| `GET /cliente/get/:id` | admin, vendedor, agropecuario, ganaderia, **almacen** ✅ |
| `POST /cliente/update` | admin, vendedor, agropecuario, ganaderia, **almacen** ✅ |
| `POST /cliente/updateAdmin` | admin, vendedor, agropecuario, ganaderia, **almacen** ✅ |
| `POST /cliente/updateExterno` | admin, vendedor, agropecuario, ganaderia, **almacen** ✅ |

**Problema**: `almacen` ya tiene permisos para crear y editar clientes en las rutas POST, pero **no puede acceder a la lista** (`GET /cliente/lista`). Sin la lista, no puede llegar a editar ningún cliente desde la pantalla de gestión.

#### Sidebar (`app/Views/partials/sidebar.php`)

El bloque `if ($userRoleName === 'vendedor')` incluye:
```php
<li class="nav-item"><a href="<?= base_url('cliente/lista') ?>" class="nav-link">Clientes</a></li>
```

El bloque `if ($userRoleName === 'almacen')` **no tiene ningún enlace a clientes**.

#### Controlador (`app/Controllers/cliente/clienteController.php`)

- `index()` — lista todos los clientes con paginación, búsqueda y filtro por estado. No tiene ninguna restricción adicional por rol dentro del método.
- `updateAdmin()` — edita cualquier cliente sin restricción de "último del día". Ya permite `almacen`.
- `update()` — edita solo el último cliente registrado por el usuario en el día. Ya permite `almacen`.

No se requieren cambios en el controlador.

---

### Acciones necesarias

#### 1. Ruta — agregar `almacen` a `GET /cliente/lista`

```php
// Antes
$routes->get('lista', 'cliente\clienteController::index', ['filter' => 'role:admin,vendedor,agropecuario,ganaderia']);

// Después
$routes->get('lista', 'cliente\clienteController::index', ['filter' => 'role:admin,vendedor,agropecuario,ganaderia,almacen']);
```

**Archivo**: `app/Config/Routes.php`

#### 2. Sidebar — agregar enlace "Clientes" en el bloque de `almacen`

Agregar dentro de la sección "Ventas" del bloque `almacen` en el sidebar:

```php
<li class="nav-item">
  <a href="<?= base_url('cliente/lista') ?>" class="nav-link">Clientes</a>
</li>
```

Se agrega en el dropdown `#sidebarVentas` del bloque `almacen`, junto al enlace existente de "Gestionar Ventas".

**Archivo**: `app/Views/partials/sidebar.php`

---

### Alcance de permisos para `almacen`

Una vez aplicados los cambios, el rol `almacen` podrá:

| Acción | Permitido | Método |
|---|---|---|
| Ver lista de clientes | ✅ | `GET /cliente/lista` |
| Buscar clientes por nombre/CI | ✅ | (incluido en `index()`) |
| Editar cualquier cliente (sin restricción de día) | ✅ | `POST /cliente/updateAdmin` |
| Crear nuevo cliente | ✅ | `POST /cliente/create` (ya existía) |

El rol `almacen` **no** tendrá acceso a:
- Activar/desactivar clientes (no existe esa ruta en el controlador)
- Eliminar clientes (no existe esa ruta en el controlador)
