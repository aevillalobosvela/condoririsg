## TAREA 8 — Resumen de crédito del receptor en POS de venta a crédito y recibos

### Solicitud del cliente

En las 3 pantallas de venta a crédito y en los 3 recibos de venta a crédito, mostrar un
resumen del estado crediticio del receptor en el período activo:

- **Saldo anterior:** lo que el receptor ya tenía acumulado **antes** de la venta actual
- **Consumo actual:** el monto de la venta que se está registrando en este momento
- **Total acumulado:** saldo anterior + consumo actual (lo que se descontará en planilla)

El período activo va del **día 11 del mes al día 10 del mes siguiente** (misma lógica que
la Tarea 6 — acumulado en recibos, ya implementada).

---

   saldo anterior / consumo actual / total acumulado — en lugar del único valor actual.

### Lógica del período activo

```
Si hoy >= día 11:
    inicio = día 11 del mes actual
    fin    = día 10 del mes siguiente
Si hoy < día 11:
    inicio = día 11 del mes anterior
    fin    = día 10 del mes actual
```

Esta lógica ya está implementada en `VentaModel::getAcumuladoCreditoPeriodo()`.

---

### Definición de los 3 valores

| Valor | Definición | Fuente |
|---|---|---|
| **Saldo anterior** | Acumulado del receptor en el período activo **sin contar la venta actual** | `getAcumuladoCreditoPeriodo()` llamado **antes** de guardar (en el POS) o restando `monto_total` de la venta actual (en el recibo) |
| **Consumo actual** | Monto de la venta que se está registrando | `$venta->monto_total` (recibo) / monto del carrito actual (POS) |
| **Total acumulado** | Saldo anterior + consumo actual | Suma de los dos anteriores |

#### Cálculo del saldo anterior en el recibo
`getAcumuladoCreditoPeriodo()` ya incluye la venta actual (fue guardada antes de generar el recibo).
Por lo tanto:
```
saldo_anterior  = getAcumuladoCreditoPeriodo() - venta->monto_total
consumo_actual  = venta->monto_total
total_acumulado = getAcumuladoCreditoPeriodo()   // sin cambios
```

#### Cálculo del saldo anterior en el POS
La venta aún no fue guardada, por lo tanto `getAcumuladoCreditoPeriodo()` devuelve directamente
el saldo anterior. El consumo actual es el monto del carrito calculado en el JS del POS.
```
saldo_anterior  = getAcumuladoCreditoPeriodo()   // llamado vía AJAX al seleccionar receptor
consumo_actual  = total del carrito (JS)
total_acumulado = saldo_anterior + consumo_actual (calculado en JS)
```

### Estrategia de implementación

#### En el recibo (3 vistas)
- `generarRecibo()` ya calcula `$acumuladoCredito` — agregar `$saldoAnterior` restando `monto_total`
- Pasar ambos valores a la vista: `acumuladoCredito` (total) y `saldoAnterior`
- La vista calcula `consumo_actual = acumuladoCredito - saldoAnterior` o usa `monto_total` directamente
- Reemplazar la línea actual `ACUMULADO PERIODO: X Bs` por el bloque de 3 líneas

#### En el POS de crédito (3 vistas)
- Agregar endpoint AJAX `GET /[modulo]/saldoCredito?tipo=uto|externo&id=X` en los 3 controllers
- El endpoint llama a `getAcumuladoCreditoPeriodo()` y devuelve JSON con `saldo_anterior` y `periodo`
- En la vista, al seleccionar un receptor (evento ya existente en el JS del buscador), hacer fetch
  al endpoint y mostrar el panel de resumen
- El panel se actualiza en tiempo real cuando cambia el carrito (el consumo actual ya está calculado en JS)
- El panel desaparece si se deselecciona el receptor

```
┌─────────────────────────────────────────┐
│  CRÉDITO PERÍODO  11/05 al 10/06        │
│  Saldo anterior:        Bs  1,210.00    │
```

- "Esta venta" se actualiza en tiempo real al modificar el carrito
- "Total a descontar" = saldo anterior + esta venta, también en tiempo real

```php
public function saldoCredito(): ResponseInterface
{
    $tipo = $this->request->getGet('tipo'); // 'uto' | 'externo'
    $id   = (int) $this->request->getGet('id');

    if (!in_array($tipo, ['uto', 'externo']) || $id <= 0) {
        return $this->response->setJSON(['saldo_anterior' => 0, 'periodo' => '']);
    }

    $saldo   = $this->ventaModel->getAcumuladoCreditoPeriodo($tipo, $id);
    $periodo = /* calcular rango del período activo */;

    return $this->response->setJSON([
        'saldo_anterior' => $saldo,
        'periodo'        => $periodo, // ej: "11/05 al 10/06"
    ]);
}
```
