## TAREA 7 — Normalización y completitud del nombre de receptor en todos los reportes de ventas

### Solicitud del cliente

Los reportes de ventas deben mostrar los nombres de los receptores/clientes en un formato
normalizado y procesable: **primero apellidos, luego nombres** (formato `PATERNO MATERNO NOMBRES`).
Además, ningún nombre debe aparecer truncado o incompleto por limitaciones de ancho de celda,
columna u otras razones técnicas. El dato nombre es crítico para validación por instituciones
externas (planillas UTO, reportes contables) y cualquier error o truncamiento invalida los documentos.

Aplica a **cualquier reporte que involucre clientes de cualquier tipo**:
- Personal UTO (`public.personas.nombre` — ya tiene formato `PATERNO MATERNO NOMBRES`)
- Clientes externos (`condoriri.clientes_externos.nombre` — formato libre, puede estar desordenado)
- Clientes contado (`condoriri.clientes.nombre_completo` — formato libre, puede estar desordenado)

#### Problema de formato en clientes contado y externos

La BD confirma que el problema existe en `condoriri.clientes` y parcialmente en
`condoriri.clientes_externos`. La normalización automática en SQL no es viable
(nombres y apellidos compuestos hacen imposible detectar el límite). La solución es:
1. Corregir manualmente los 3 registros de `clientes_externos` (scripts arriba).
2. Agregar texto de ayuda en formularios de alta para nuevos registros.
3. En reportes, mostrar el nombre completo sin truncar — sin reordenar.

El formato `PATERNO MATERNO NOMBRES` ya está garantizado para personal UTO (`p.nombre`).

### Consideraciones de implementación para PDFs

En FPDF, `Cell()` trunca silenciosamente el texto que supera el ancho. Para nombres largos
en la tabla matricial (donde el ancho de la columna de nombre es dinámico `$labelWidth`),
la solución es calcular si el texto cabe y, si no, usar `MultiCell` ajustando la altura
de toda la fila:

```php
// Patrón recomendado para filas con nombre largo en tabla matricial
$nbLines = $this->NbLines($labelWidth, $venta['cliente']);
$rowH    = max(5, $nbLines * 5); // altura mínima 5mm

// Renderizar con MultiCell para el nombre, Cell para el resto
$x = $this->GetX(); $y = $this->GetY();
$this->Cell($wNro, $rowH, $nro++, 1, 0, 'C', $fill);
// ... celdas de productos ...
$this->SetXY($x + $wNro, $y);
$this->MultiCell($labelWidth, 5, $venta['cliente'], 1, 'L', $fill);
// reposicionar y continuar con el resto de columnas
```

Este patrón ya existe en `mostrarVentas()` de `CierreVentaBasePdf` para los ítems de producto
— se aplica el mismo enfoque a la columna de nombre en la tabla matricial.
